# mine_plugin — Maple Blocks (Клён)

Плагин для Paper 1.21.1 + ресурспак, добавляющие два «чистых» кастомных блока на базе **нотного блока** (настоящий деревянный блок: правильный инструмент — топор, ванильные звуки дерева, деревянная прочность):

| Блок | Предмет | Ванильный BlockState | CustomModelData |
|---|---|---|---|
| **Клён** (Maple Log) | `note_block` | `note_block[instrument=didgeridoo,note=1]` | `1001` |
| **Листва клёна** (Maple Leaves) | `note_block` | `note_block[instrument=didgeridoo,note=2]` | `1002` |

## Почему note_block и почему эти состояния безопасны

У нотного блока 1150 состояний (`instrument` × `note` × `powered`), из которых ванильному геймплею реально нужны единицы. Инструмент нотного блока пересчитывается от блока снизу **только через physics-update**. Плагин отменяет `BlockPhysicsEvent` для всех нотных блоков, поэтому:

- ванильный нотный блок навсегда остаётся `harp` и **никогда** не может стать `didgeridoo`;
- зарезервированные состояния `didgeridoo/note=1..2` недостижимы в выживании;
- ресурспак перекрашивает ровно эти состояния — обычные нотные блоки выглядят и звучат как в ванилле (клик-настройка нот работает).

Это тот же подход, который используют ItemsAdder и Oraxen.

## Сборка плагина

Требуется JDK 21 и Maven:

```bash
mvn clean package
```

Готовый jar: `target/MapleBlocks-1.1.0.jar` → положить в папку `plugins/` сервера Paper 1.21.1.

## Установка ресурспака

Заархивируйте **содержимое** папки `resourcepack/` (так, чтобы `pack.mcmeta` был в корне zip):

```bash
cd resourcepack && zip -r ../MapleBlocks-ResourcePack.zip . && cd ..
```

Затем либо положите zip в `resourcepacks/` клиента, либо раздавайте с сервера через `resource-pack=` в `server.properties`.

## Использование

- `/maple give log [кол-во]` — выдать Клён
- `/maple give leaves [кол-во]` — выдать Листву клёна
- Право: `mapleblocks.give` (по умолчанию op)

## Игровое поведение

- **Клён**: ставится/ломается со звуками дерева (нотный блок — деревянный), топор ломает быстрее, дроп выпадает всегда (как у ванильных брёвен), без лишнего lore.
- **Листва клёна**: звуки листвы при установке и разрушении, дроп **только ножницами** (как у ванильной листвы).
- Правый клик по кастомным блокам не «настраивает ноту» — их состояние неизменно; установка блоков вплотную к ним работает как обычно.
- Взрывы обрабатываются: клён дропает себя, листва сгорает без дропа (ванильное поведение).
- Идентификация предметов через PersistentDataContainer (ключ `mapleblocks:maple_block`) — надёжнее, чем только CustomModelData.

## Известные ограничения метода

- Плагин глобально блокирует физику нотных блоков: ванильные нотные блоки **всегда звучат как harp** (инструмент не меняется от блока снизу). Клик-настройка ноты и проигрывание по-прежнему работают. Это стандартная цена метода (так же поступают ItemsAdder/Oraxen).
- Прочность блоков = прочности нотного блока (hardness 0.8) — ломаются немного быстрее ванильных брёвен (2.0).
- Pick-block (СКМ в креативе) вернёт ванильный нотный блок.
- При установке/разрушении листвы под звуком листвы слышен ванильный деревянный звук (его нельзя отменить со стороны сервера).
