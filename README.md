# mine_plugin — Maple Blocks (Клён)

Плагин для Paper 1.21.1 + ресурспак, добавляющие два «чистых» кастомных блока:

| Блок | Предмет | Ванильный BlockState | CustomModelData |
|---|---|---|---|
| **Клён** (Maple Log) | `note_block` | `note_block[instrument=didgeridoo,note=1]` | `1001` |
| **Листва клёна** (Maple Leaves) | `red_mushroom_block` | `red_mushroom_block[up=true,down=true,north/south/east/west=false]` | `1002` |

## Почему не oak_log / oak_leaves

Метод «занятых BlockState» работает только с блоками, у которых есть **недостижимые** состояния. У `oak_log` всего 3 состояния (`axis=x/y/z`) — все используются игрой. У `oak_leaves` 28 состояний — и все достижимы в выживании (например, `distance=7,persistent=false` возникает у каждой срубленной кроны за мгновение до распада листвы). Резервировать там нечего: перекраска сломала бы настоящие дубовые блоки по всему миру. Поэтому:

- **Клён** — нотный блок (настоящее дерево: топор, звуки дерева, hardness 0.8). Плагин отменяет физику всех нотных блоков, поэтому ванильный ноутблок навсегда остаётся `harp` и зарезервированное состояние `didgeridoo` недостижимо в выживании.
- **Листва** — грибной блок (не интерактивный: ставится вплотную без шифта; ломается быстро, как листва, hardness 0.2). Комбинация граней `up+down` без боков не встречается ни в генерации, ни при установке игроком (игрок всегда ставит гриб-блок со всеми гранями `true`).

## Фикс стакания (v1.2.0)

Ванильный клиент не ставит блоки на нотный блок без шифта (правый клик = «настроить ноту»). Плагин перехватывает клик по Клёну и выполняет установку блока **на стороне сервера**: вызывается обычный `BlockPlaceEvent` (совместимость с плагинами защиты), расходуется предмет, играет звук. Клён стакается как обычное бревно.

## Модели предметов: два формата

- `assets/minecraft/models/item/*.json` со `overrides` по `custom_model_data` — для клиентов **1.21.1–1.21.3**;
- `assets/minecraft/items/*.json` (новый формат item definitions, `range_dispatch`) — для клиентов **1.21.4+**.

Благодаря этому кастомные текстуры видны в инвентаре независимо от версии клиента.

## Сборка плагина

Требуется JDK 21 и Maven:

```bash
mvn clean package
```

Готовый jar: `target/MapleBlocks-1.2.0.jar` → положить в папку `plugins/` сервера Paper 1.21.1.

## Установка ресурспака

Заархивируйте **содержимое** папки `resourcepack/` (так, чтобы `pack.mcmeta` был в корне zip):

```bash
cd resourcepack && zip -r ../MapleBlocks-ResourcePack.zip . && cd ..
```

Затем либо положите zip в `resourcepacks/` клиента, либо раздавайте с сервера через `resource-pack=` в `server.properties`. После смены пака в игре нажмите **F3+T**.

## Использование

- `/maple give log [кол-во]` — выдать Клён
- `/maple give leaves [кол-во]` — выдать Листву клёна
- Право: `mapleblocks.give` (по умолчанию op)

## Игровое поведение

- **Клён**: звуки дерева, топор ломает быстрее, дроп всегда (как у брёвен), стакается и обстраивается без шифта, правый клик не настраивает ноту, редстоун не проигрывает звук.
- **Листва клёна**: звуки листвы при установке/разрушении, ломается быстро, дроп **только ножницами** (как у ванильной листвы), не интерактивна.
- Взрывы: клён дропает себя, листва сгорает без дропа (ванильное поведение).
- Идентификация предметов через PersistentDataContainer (`mapleblocks:maple_block`) — надёжнее, чем только CustomModelData.

## Защита состояний блоков (v1.3.0)

Minecraft на каждом обновлении соседей пересчитывает у нотного блока **инструмент** (от блока снизу), а у грибного — **соединение граней** (с соседними такими же блоками). Это выбивало наши блоки из зарезервированного состояния (бревно → обычный ноутблок, листва → текстура гриба). `BlockPhysicsEvent` Paper гарантированно вызывается только для «корневого» блока обновления, поэтому соседние блоки часто проскакивали.

Решение (работает без правки конфигов):
1. отмена `BlockPhysicsEvent` для `note_block` и `red_mushroom_block` (ловит корневые обновления);
2. перед каждой установкой/разрушением/взрывом плагин запоминает соседние кастомные блоки и **переустанавливает их точное состояние на следующий тик** (ловит соседние обновления, которые событие пропускает).

Для гарантированного отсутствия любого мерцания дополнительно включите в `config/paper-global.yml`:

```yaml
block-updates:
  disable-noteblock-updates: true
```

## Известные ограничения метода

- Ванильные нотные блоки на сервере **всегда звучат как harp** (физика нотных блоков заблокирована, инструмент не меняется от блока снизу). Настройка нот кликом и проигрывание работают. Стандартная цена note_block-метода (так же у ItemsAdder/Oraxen).
- При серверной установке блока против Клёна блоки с ориентацией (ступени, брёвна, печки) ставятся в положении по умолчанию — клиент не передаёт данные прицела при клике по «интерактивному» блоку.
- Pick-block (СКМ в креативе) вернёт ванильный блок-носитель.
- Под звуками листвы слышен тихий ванильный звук грибного блока (не отменяется со стороны сервера).
